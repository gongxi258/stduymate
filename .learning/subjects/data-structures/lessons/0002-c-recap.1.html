指针：变量住在哪里

本节目标：能用地址与解引用解释一段指针代码的每一步

一个值，两个名字

先读一段程序。它只有十行，但包含了本课要讲的每一个动作：声明一个变量、取它的地址、把地址存进另一个变量、顺着这个地址把值改掉。

#include <stdio.h>

int main(void) {
    int x = 20;
    int *p = &x;          /* &x 是 x 的地址，p 把这个地址存了下来 */

    printf("x  = %d\n", x);
    printf("*p = %d\n", *p);   /* *p 是「按 p 里这个地址去访问」 */

    *p = 35;              /* 顺着地址写进去 */

    printf("x = %d, *p = %d\n", x, *p);
    return 0;
}

输出的关键部分是：

x  = 20
*p = 20
x = 35, *p = 35

*p = 35 这一行里，p 从头到尾没有被赋值，可 x 从 20 变成了 35。要解释这一步，需要回答两个问题：&x 取到的究竟是什么？*p 访问的究竟是哪一格？本课的目标就是让这段程序里的每一行都能读出一个确定的地址。

变量住在哪个格子里

程序运行时用到的数据都放在内存（memory）里。内存按字节编号，每个字节有一个编号，这个编号称为地址（address）。编号是一串数字，用 %p 打印出来就能看到，程序里任何一格都能按编号找到。

一个变量就是给一块数据起的名字。编译器在编程序时给它划出若干字节，从此这个名字与那段地址绑在一起。所以每个变量同时有两个可以观察的量：名字与地址。

前一段程序里 x 的地址是这么打印出来的：

printf("&x = %p\n", (void *)&x);

& 是取地址运算符，&x 读作「x 的地址」。打印地址要写成 (void *)&x，%p 这个格式只接受这种通用指针，原因留到后面几课再讲，这里照写即可。程序跑起来，屏幕上会出现一行像这样的输出：

&x = 00000011D5DFFDB4

这一串数字每次运行都会变：操作系统给程序分到的内存位置不固定。所以读地址时值得看的是两个地址之间的关系，某一次的具体数字看过就算。下面这段程序把变量的宽度与彼此的距离都问了出来：

#include <stdio.h>

int main(void) {
    int x = 20;
    int y = 30;

    printf("sizeof(int) = %zu\n", sizeof(int));
    printf("&x = %p\n", (void *)&x);
    printf("&y = %p\n", (void *)&y);
    printf("&y - &x = %td\n", (char *)&y - (char *)&x);
    return 0;
}
sizeof(int) = 4
&x = 0000004B409FFD0C
&y = 0000004B409FFD08
&y - &x = -4

sizeof(int) 是 4，说明一个 int 变量占 4 个字节；这一版编译器把 y 安排在了 x 下面 4 个字节处。最后一行写成 (char *)&y - (char *)&x，是因为两个 char * 相减的单位是字节：结果 -4 说明 y 的编号比 x 小 4。

图里画的就是这段程序的内存状态。编号大的格子画在上面，格子上标的是它的起始编号；两个变量的编号差多少，就是它们在内存里隔了多少字节。

指针就是存放地址的变量

知道了变量有地址，就可以说明本课的主角了。

指针（pointer）是存放地址的变量；这个地址指向哪块内存，指针就能间接访问哪块内存。声明指针时要把所指的类型写在星号前面：

int  *p;    /* p 是指向 int 的指针：装着一个 int 变量的地址 */
char *c;    /* 同样是「类型名 + 星号 + 变量名」；这里 c 用来装一个 char 变量的地址 */

星号前面写什么类型，指针就指向什么类型。int *p 里的这个 * 是声明的一部分，它的作用是把 p 声明成指针类型，读作「p 是指向 int 的指针」。写 int* p 也合法、意思完全相同，两种写法在程序里的效果一样。要注意的是这个 * 只跟着紧邻它的那个名字走：int *p, k; 里 p 是指针、k 是普通的 int 变量，两个都要指针得写成 int *p, *k;。

指针自己也是一个变量，因此它同样住在某个格子里、同样有自己的地址。这一点值得单独看一眼：&p 与 &x 是两个不同的编号，p 的内容是 x 的地址，而 p 自己的地址是另一个数。

#include <stdio.h>

int main(void) {
    int x = 20;
    int *p = &x;

    printf("x  = %d\n", x);
    printf("p  = %p   （p 的内容：x 的地址）\n", (void *)p);
    printf("&p = %p   （p 自己的地址）\n", (void *)&p);
    printf("sizeof(p) = %zu\n", sizeof(p));
    return 0;
}
x  = 20
p  = 00000011D5DFFDB4   （p 的内容：x 的地址）
&p = 00000011D5DFFDA8   （p 自己的地址）
sizeof(p) = 8

sizeof(p) 是 8，而 sizeof(int) 是 4：在这一版编译器上，一个指针固定占 8 字节，与它指向什么类型无关。

这里有一个最容易混的地方，值得单独摆出来。* 在 C 里承担了两个不同的角色：

出现的位置例子含义
声明里int *p = &x;类型记号：p 是一个指向 int 的指针
表达式里*p解引用：按 p 里的地址去访问那一格

同一个符号，前者描述「p 是什么」，后者描述「顺着 p 去哪里」。读别人的代码时先看清它落在哪一边。与之配对的是 &：&x 取变量的地址，&p 取指针变量自己的地址。

顺着地址取值

解引用（dereference）指按一个指针里记的地址去访问它所指向的那一格，也就是「顺着地址取值」。它是本课最核心的动作，因为它把「间接」这件事落到了具体的一格上：*p 访问的那一格由 p 的内容决定，与 p 自己所在的格子无关。

上一节那段程序已经演示了它。接下来换个角度：让 p 先指 x、再指 y，看同一个 *p 两次读到的东西是否相同。

#include <stdio.h>

int main(void) {
    int x = 20, y = 30;
    int *p = &x;

    printf("*p = %d\n", *p);     /* p 指着 x */
    p = &y;                      /* 改成指着 y：改的是 p 自己的内容 */
    printf("*p = %d\n", *p);
    *p = 35;                     /* 顺着地址写 */
    printf("*p = %d, y = %d, x = %d\n", *p, y, x);
    return 0;
}
*p = 20
*p = 30
*p = 35, y = 35, x = 20

三行输出连起来是解引用的完整语义：

  • p = &y 只改了 p 装着哪个地址，x 与 y 的内容都没动；
  • *p = 35 改的是 p 当前指着的 y，所以 y 变成 35，而 x 仍然是 20；同一个写法在前一段程序里改的是 x，因为那时 p 指 x。

解引用写在赋值号左边，改的就是那一格的内容；写在右边，读到的是那一格的内容。

关于空指针与未初始化指针：int *p; 这样只声明不赋值，p 里是一段没有意义的比特，这时候读或写 *p，结果是不可预期的，可能给出一个乱七八糟的值，也可能让程序直接结束。C 用空指针表示「不指向任何东西」：

int *p = NULL;      /* p 显式地不指向任何对象 */

对空指针求值是有明确规定的：判定 p == NULL 或 if (p) 都是合法操作，也是后面接住内存申请结果的落点；而 *p 里的 p 一旦为空，程序的行为就没有规定了。这条阅读习惯可以现在就养成：看到 *p 或者 p->name 这样的写法，先确认 p 指着东西。（-> 读作「顺着指针去取成员」，下一课讲结构体时再展开。）

传出去的是副本

函数调用是解引用最常见的用场。参数传递这一步可以拆成两个各自独立的问题，本节后面每一处调用都能拿它们各问一次：

  1. 函数拿到的是原件还是副本？ 这由 C 的参数传递规则决定，每一次调用都一样：函数里的参数得到的是副本，调用方那个变量本身不进函数。
  2. 这个副本里装的是什么？ 这由实参写成什么样决定：调用处写 x、y，副本里装的就是它们的值；写 &x、&y，副本里装的就是它们的地址。

两问各有各的答案，而两个答案同时成立。先看一个没起作用的交换：

#include <stdio.h>

void swap_wrong(int a, int b) {
    int t = a;
    a = b;
    b = t;
}

int main(void) {
    int x = 3, y = 8;
    swap_wrong(x, y);
    printf("x = %d, y = %d\n", x, y);
    return 0;
}
x = 3, y = 8

函数体里那三行确实交换了两个值，可调用方这份 x、y 一点没变。拿上面两问对着这次调用各问一次：标准对这一步的规定是「实参先被求值，每个参数被赋予对应实参的值」，所以 a、b 是函数调用时新划出来的两格，main 里的 x、y 没有进函数——第一问的答案是副本；调用处写的是 x、y 两个名字，它们求值得到的 3 和 8 就是这两格里装的内容——第二问的答案是值。函数里改的一直是 a、b 这两格，main 里的 x、y 从头到尾没被碰过。

要让函数改动调用方的变量，就得把地址传进去，让它在函数里通过解引用写回原格：

void swap_right(int *pa, int *pb) {
    int t = *pa;
    *pa = *pb;
    *pb = t;
}

int main(void) {
    int x = 3, y = 8;
    swap_right(&x, &y);
    printf("x = %d, y = %d\n", x, y);
    return 0;
}
x = 8, y = 3

这次两个名字都换过来了。函数体同样只有三行赋值，起作用的差别发生在参数传递那一步：swap_wrong 收到的是 3 和 8，swap_right 收到的是 x 与 y 的地址。pa、pb 依然是副本，但副本里装的是地址，顺着地址就能回到调用方那一格。C 里只有一套参数传递规则，都是传值；要让函数改动调用方的变量，就传地址过去。

把两问在两个函数上并排摆出来：

问的传值版传地址版
调用写成swap_wrong(x, y)swap_right(&x, &y)
① 拿到的是原件还是副本？副本副本
② 副本里装的是什么？值：3、8地址：&x、&y
函数里改的是哪几格？a、b 这两格顺着 pa、pb 摸到的 x、y 两格
main 里的 x、y没变，还是 3、8变了，打印出 x = 8, y = 3

① 那一行两列相同，② 那一行两列不同，参数传递的差别就落在这一处：是不是副本由传递规则定，副本里装什么由实参的写法定。

第二列按编号走一遍，两问的答案都会落到具体的格子上。设 x 在 0x7ffd38、y 在 0x7ffd3c（沿用下面那张图的编号）：

  1. 调用 swap_right(&x, &y)，两个实参求值得到 0x7ffd38 与 0x7ffd3c 这两个编号。
  2. 第一问：pa、pb 是调用时新划出来的两格，各自有自己的编号（用 &pa、&pb 打印得出来），与 main 的 x、y 合起来是四块不同的格子——它们是副本。
  3. 第二问：这两格里装的内容是第 1 步求出的编号，pa 里是 0x7ffd38，pb 里是 0x7ffd3c。
  4. int t = *pa; 顺着 pa 里的 0x7ffd38 摸到 main 的 x，读出 3。
  5. *pa = *pb; 把 pb 指着的 y 的内容写进 pa 指着的那一格，写的是 main 的 x；*pb = t; 写的是 main 的 y。这两行解引用落在调用方那两格上，调用方看得见。

swap_wrong 的 a、b 在第 3 步之后就断了：两格里装的是 3 和 8，没有编号可以顺着往回走。读题时先认问的是哪一问——问「传出去的那两个值是什么」，要答的是第二问，也就是副本里装的 &x、&y 这两个编号；问「函数拿到的是原件还是副本」，要答的是第一问。两问分开答，「传出去的是副本」与「传出去的是地址」就能同时成立，合起来是一次完整的说法：传出去的是一个装着地址的副本。

记法：副本不副本，管的是「改的是不是原件那一格」；副本里装什么，管的是「能不能顺着它摸到原件」——装值摸不到，装地址摸得到。

数组名与指针

指针与数组的关系，是上面这套地址算术最直接的用法。看 int a[4] = {10, 20, 30, 40}; 这一行：数组在内存里就是 4 个挨着的 int 格，a 这个名字在多数场合被当作首元素的地址来用。

#include <stdio.h>

int main(void) {
    int a[4] = {10, 20, 30, 40};
    int *p = a;                  /* 数组名在这里就是首元素的地址 */

    printf("a      = %p\n", (void *)a);
    printf("p      = %p\n", (void *)p);
    printf("a[2]   = %d\n", a[2]);
    printf("*(p+2) = %d\n", *(p + 2));
    printf("(p+1) 比 p 大 %td 字节\n", (char *)(p + 1) - (char *)p);
    return 0;
}
a      = 000000E4975FFB10
p      = 000000E4975FFB10
a[2]   = 30
*(p+2) = 30
(p+1) 比 p 大 4 字节

p = a 之后 p 与 a 打印出同一个编号，说明数组名给出的就是首元素的地址。更值得看的是最后一行：p + 1 只加了 1，地址却前进了 4 个字节——正好是一个 int 的宽度。

这里就显出了前面留下的那个问题：指针类型为什么必须写清楚。p + 1 指的是「下一个 int」，编译器按 sizeof(int) 折算出要加的字节数；如果 p 是 char *，同样写 p + 1 就只前进 1 个字节。指针加减的单位是它所指类型的宽度，指针类型决定解引用读几字节、加减走几步。

由此，C 里访问数组元素有两种写法，它们说的是同一个格子：

写法含义
a[2]数组第 2 个元素
*(p + 2)从 a 出发走 2 个元素，再解引用

这两种写法可以互相替换，正是 C 把数组与指针绑在一起的起点。

把这一课与本科目的主线接上。链表的每一个结点里，除了数据，还要存一个指向下一个结点的指针；所谓「从头结点开始往后走一个」，就是取 next 里那个地址，再解引用到下一个结点上。下一课把这些指针对准结构体，链表的结点就是「数据加一个装地址的成员」。项目里结点的申请与释放还要再往后一课，而指针是走通那条链的唯一入口。

本课的代码都只有十行上下，不要求写完整程序：敲一遍、改一行、看输出。本课之后，指针会在每一课里出现——结构体的成员访问、链表结点的串联、动态数组返回的那块内存，用的都是这一套地址与解引用。

练习 第 1 步 · 打印一个变量的地址

先只写这几行，跑出你自己的那份输出。

#include <stdio.h>

int main(void) {
    int x = 20;

    printf("x  = %d\n", x);
    printf("&x = %p\n", (void *)&x);
    printf("sizeof(x) = %zu, sizeof(int) = %zu\n", sizeof(x), sizeof(int));

练习 第 4 步 · 看看交换到底改了谁

先只写 swap_wrong 和它的调用，跑一次：

#include <stdio.h>

void swap_wrong(int a, int b) {
    int t = a;
    a = b;
    b = t;
}

int main(void) {
    int x = 3, y = 8;
    swap_wrong(x, y);
    printf("x = %d, y = %d\n", x, y);
    return 0;
}

然后把 swap_right 加进去，把 main 里的调用换成 swap_right(&x, &y);，再跑一次：

void swap_right(int *pa, int *pb) {
    int t = *pa;
    *pa = *pb;
    *pb = t;
}
  1. 在 swap_right 里加一行 printf("pa = %p\n", (void *)pa);，它打印的地址和 main 里哪个变量对得上？

小结

  • 地址是内存里某一格的编号；变量一旦被划出空间，就有名字与地址两个可观察的量。
  • 指针是存放地址的变量；&x 取变量的地址，*p 按 p 里的地址访问它指向的那一格。
  • * 在声明里是类型记号（int *p 说明 p 的类型），在表达式里是解引用（*p 是那一格的内容），两者的读法要分开。
  • 指针类型决定解引用读几字节、加减走几步：p + 1 前进的是「一个所指类型的宽度」。
  • 函数参数是副本；副本里装的是地址时，函数才能顺着地址改到调用方的变量——swap 正是这件事最小的一例。
  • 数组名在多数场合就是首元素地址，a[i] 与 *(p + i) 等价。
